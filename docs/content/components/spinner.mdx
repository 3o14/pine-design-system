# Spinner

Shows that something is loading when progress can't be measured, such as waiting on a network response or rendering a region. It renders `role="status"` with a visually hidden `label`, so screen readers announce it politely when it appears. When you can measure progress, use [ProgressBar](/components/progress-bar) instead.

### Label

`label` is read by screen readers and is not shown on screen. It defaults to `"Loading"`; describe what is loading when the context isn't obvious. If you also show visible text, hide that text from assistive technology so it isn't announced twice.

<ComponentPreview code={`<Spinner size="small" label="Loading comments" />
<span aria-hidden="true">Loading comments…</span>`}>
  <SpinnerLabelDemo />
</ComponentPreview>

### Decorative

Set `decorative` when the spinner is only visual: it renders no `role` and no label, and is hidden from assistive technology. Use it in two cases:

- **Inside a button or other control.** ARIA treats a control's content as presentational, so a status region inside a `<button>` is never announced, and its label would leak into the button's name (e.g. "Loading Save"). Announce the loading state through the button's own text instead, such as changing "Save" to "Saving…".
- **When several spinners are shown together.** Each regular Spinner is its own live region, so a row of them would announce "Loading" again and again. Keep one regular Spinner for the region that is loading and make the rest decorative.

While the action is running, use `aria-disabled="true"` and ignore clicks rather than `disabled`: a focused button that becomes `disabled` drops keyboard focus to the page.

<ComponentPreview code={`<button type="button" aria-disabled="true">
  <Spinner size="small" decorative />
  Saving…
</button>`}>
  <SpinnerDecorativeDemo />
</ComponentPreview>

## Guidelines

### Spinner vs ProgressBar

- **Spinner**: progress can't be measured and the wait is short.
- **ProgressBar**: progress can be measured (upload bytes, completed steps), or the wait is long enough that users need to know how much is left.

Don't keep a Spinner on screen indefinitely — switch to a result or error state as soon as you can.

### Motion

In the game theme the spinner steps through eight positions instead of rotating smoothly. When the user has turned on `prefers-reduced-motion`, it slows down instead of stopping, so the loading signal isn't lost.
